# Fotos

- `assets/img/<slug>.jpg` → wird automatisch in der Website verwendet (Slug = Dateiname der Leistungsseite, z. B. `gravur`, `stempel`, `schuhreparatur`).
- `fotos/wartet-auf-freigabe/` → bearbeitete Fotos, die noch NICHT veröffentlicht werden dürfen (z. B. fremde Marken ohne Erlaubnis).
  - `gravur-parfum.jpg`: Flakons „NOUR by Babrak Music“ (Marke eines Kollegen). Erst nach dessen Erlaubnis nach `assets/img/gravur.jpg` verschieben.
- Keine Fotos mit Namen von Privatpersonen oder Prominenten veröffentlichen.
